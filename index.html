PROJECT 1

ResumeYouNeed (AI Resume Builder & ATS Analyzer)

A comprehensive two-way platform designed for both students and HR recruiters. Students build and optimize ATS-compliant resumes against specific job descriptions in 60 seconds, while HR teams use the evaluation portal for candidate screening and side-by-side two-resume comparison to select top talent with confidence.

  • Two-Way Platform
  • Student Portal
  • HR Evaluation
  • Two-Resume Comparison
  • ATS Analyzer
  • FastAPI / React
+ The messy, real version

Problems I faced

Most resume builders only cater to the applicant side, ignoring how HR screening software and hiring managers actually evaluate candidates. Furthermore, recruiters lacked a fast, objective way to compare two competing resumes side-by-side against the same job requirements to evaluate relative skill density and experience metrics.

How I solved it

I architected a dual-portal system: an intuitive Student workspace for real-time ATS optimization, and an HR evaluation dashboard. I engineered a two-resume comparison engine that parses two candidates' resumes concurrently, benchmark-scores both against the job description, and visualizes skill overlaps, keyword gaps, and quantifiable achievement metrics side-by-side.

Result
🏆 1st Prize — GDG BCET Hackathon (TechSprint) ⚡ Complete ATS Tailoring in 60s 👥 Two-Way Student & HR Portals ⚖️ Two-Resume Comparison

PROJECT 2

SignVoiceAI — Real-Time Sign to Text System

An assistive computer vision and machine learning system that translates real-time Indian Sign Language (ISL) and ASL gestures directly into instant text. Uses OpenCV for real-time video frame processing and hand feature extraction, classified by a trained Random Forest ML model for 96% accuracy with sub-30ms response.

  • Computer Vision
  • OpenCV
  • Random Forest
  • Machine Learning
  • Real-Time Sign to Text
  • Fast Inference
+ The messy, real version

Problems I faced

Heavy deep neural networks often require dedicated GPU runtimes and introduce lag (over 1.5 seconds) that disrupts real-time sign-to-text readability. Additionally, complex video models struggle with fluctuating webcam lighting and high computational overhead on standard laptops.

How I solved it

I utilized OpenCV for efficient frame capture, contour tracking, and normalized geometric feature extraction from hand regions. Instead of a cumbersome neural net, I trained an optimized Random Forest machine learning model on the spatial feature vectors. This delivered 96% sign-to-text accuracy with instantaneous, sub-30ms CPU-only inference, producing fluid real-time captions with zero lag.

Result
🥈 Runner-up — IEEE Hackathon at BCET 🎯 96% Sign-to-Text Accuracy ⚡ OpenCV + Random Forest ML
